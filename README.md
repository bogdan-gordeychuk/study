## Задача 1: разрешение для действия агента

Открой `src/App.tsx`. Начни с `onEvent` и обработки `approval_requested`: запиши действие по `actionId`, повтор события не должен создавать вторую карточку или сбрасывать её состояние. Кнопки слева подают тестовые события. Остальной код уже запускается.

После этого добавь в карточку кнопки решения, вызов `decide(actionId, decision)` из `src/agent.ts`, состояния отправки, ошибки и результата. Событие `action_completed` можно считать успехом только после подтверждённого разрешения. Дубли события должны быть безвредны. Оценочное время: 2–3 часа. Не нужно подключать настоящую модель или сервер.

Для проверки пришли ссылку на сохранённый проект StackBlitz или запиши изменения в этот GitHub-репозиторий и напиши «проверь». Я просмотрю изменённый код и поведение, дам короткий разбор и следующую задачу. Если работаешь локально, можно прислать архив или diff.

Важно: это симуляция интерфейса. В настоящем продукте разрешение на действие проверяется сервером.
