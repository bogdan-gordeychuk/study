## Сейчас: шаг 1 — одно состояние

Открой `src/App.tsx`. На странице есть задача «Проверить отчёт», статус «В работе» и кнопка. Кнопка вызывает `toggleDone`, но функция пока пустая.

**Твоя часть:** внутри `toggleDone` обнови состояние `done` на противоположное. Другие файлы менять не нужно.

**Проверка:** первое нажатие показывает «Готово» и меняет надпись кнопки на «Вернуть в работу»; второе возвращает «В работе». Не меняй текст страницы напрямую через DOM — он уже зависит от `done`.

**Подсказка:** `setDone` меняет состояние. Посмотри на значение, которое передаётся в этот setter. Готовое выражение здесь намеренно не написано.
